# Phiếu khảo sát nghiệp vụ tiệm spa thú cưng

Phiên bản 0.1 · Ngày 2026-11-13 · Người phụ trách thu thập: Lộc (TV4) · Mạnh chỉ chuẩn bị mẫu trống.

> Mẫu trống. **Không điền dữ liệu giả.** Kết quả khảo sát chỉ được đưa vào tài liệu khi có dữ liệu thật từ 3–5 tiệm spa (HUMAN-PENDING). Dữ liệu khảo sát chỉ dùng để đối chiếu các giá trị `[Cần chốt]` của SRS §6 và §10.B.

## A. Quy trình đặt lịch

| Câu hỏi | Trả lời |
| --- | --- |
| A1. Khách đặt lịch qua kênh nào? (điện thoại, Zalo, Facebook, website, trực tiếp) | |
| A2. Có yêu cầu khách chọn trước dịch vụ không? Nếu có, khách có biết trước thời lượng và giá không? | |
| A3. Có cho chọn nhân viên/groomer không? Có bắt buộc không? | |
| A4. Có bắt buộc xác nhận lịch qua điện thoại/Zalo không? | |
| A5. Một lịch gồm nhiều dịch vụ cho một thú cưng có được không? Tối đa mấy dịch vụ? | |

## B. Khung giờ làm việc

| Câu hỏi | Trả lời |
| --- | --- |
| B1. Giờ mở cửa và giờ đóng cửa? | |
| B2. Slot bao nhiêu phút? (15 / 30 / 60) | |
| B3. Thời lượng mỗi loại dịch vụ (cắt, tắm, chải, cắt móng, chăm da)? | |
| B4. Có giờ nghỉ trưa không? Có ngày nghỉ định kỳ không (ngày nào)? | |
| B5. Khoảng cách tối thiểu giữa hai lịch của cùng groomer? | |

## C. Chính sách hủy

| Câu hỏi | Trả lời |
| --- | --- |
| C1. Khách được hủy miễn phí khi nào? Có quy định số giờ tối thiểu không? | |
| C2. Có thu cọc không? Tỷ lệ cọc là bao nhiêu? | |
| C3. Hủy muộn thì giữ cọc hay mất cọc? Có hoàn một phần không? | |
| C4. Khách đến muộn thì xử lý thế nào? Có đánh dấu no-show không? | |
| C5. Nhân viên/groomer hủy lịch thì xử lý thế nào? | |

## D. Cọc và thanh toán

| Câu hỏi | Trả lời |
| --- | --- |
| D1. Cọc được thanh toán bằng cách nào? (tiền mặt, chuyển khoản, ví điện tử) | |
| D2. Có giới hạn hạn mức cọc không? | |
| D3. Phần còn lại thanh toán khi nào? Có thu tiền mặt tại chỗ không? | |
| D4. Có trường hợp nào không thu cọc (khách vãng lai, lịch hộ khách)? | |

## E. Phụ phí

| Câu hỏi | Trả lời |
| --- | --- |
| E1. Có phụ phí lông dài/lông dày không? Mức phần trăm? | |
| E2. Có phụ phí theo cân nặng, theo giống, theo kích cỡ không? | |
| E3. Có phụ phí phát sinh khi dịch vụ kéo dài quá dự kiến không? | |
| E4. Phụ phí được tính trên từng dịch vụ hay trên tổng hóa đơn? | |

## F. Cách tính giá

| Câu hỏi | Trả lời |
| --- | --- |
| F1. Bảng giá tính theo loài (chó/mèo) và cân nặng? Các mốc phân nhóm cân nặng là gì? | |
| F2. Có chương trình giảm giá cho khách thân hoặc thành viên không? Mức giảm? | |
| F3. Có mã khuyến mãi, đơn tối thiểu, hạn dùng không? | |
| F4. VIP và mã khuyến mãi có cộng dồn không? | |
| F5. Có bảng giá theo mức cân nặng khác nhau cho từng dịch vụ không? | |

## G. Giới hạn và quy định khác

| Câu hỏi | Trả lời |
| --- | --- |
| G1. Mỗi khách được đặt tối đa mấy lịch cùng lúc? Có giới hạn số thú cưng mỗi tài khoản không? | |
| G2. Có yêu cầu đặt trước tối thiểu / tối đa bao nhiêu giờ không? | |
| G3. Có ghi nhận lịch bùng (no-show) và phạt gì không? | |
| G4. Lịch có thể đổi sang ngày khác không? Hạn chót đổi lịch? | |
